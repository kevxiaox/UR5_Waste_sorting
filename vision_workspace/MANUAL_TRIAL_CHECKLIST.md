# 人工试验现场记录顺序

每个关键位置先停止、记录、核对保存成功，再进入下一步。现场人员负责选择路径、判断间隙并操作；助手不发送运动或夹爪写入。此清单不是自动执行程序或路径批准。

1. 上方接近：程序停止、机器人静止后记录 `PICK_APPROACH`，核对输出及保存路径。
2. 两指对准物体两侧中部、与桌面有间隙：闭爪前记录 `PICK_GRASP`，核对成功后再由现场人员闭爪。
3. 记录闭爪后的实际观察；若调整了机械臂位置，重新采集 `PICK_GRASP`，不能用调整前的记录替代。输出电平不代表夹持成功。
4. 短距离抬升、停住观察，记录是否滑动；失败即停下检查，保留失败证据。
5. 到目标区上方后，先记录对应 `LEFT_DROP_APPROACH` 或 `RIGHT_DROP_APPROACH`，核对后再继续。
6. 到实际带载放置位置、物体得到承托且夹指不碰桌面后，在张爪前记录 `LEFT_DROP_RELEASE` 或 `RIGHT_DROP_RELEASE`，核对成功后再释放。
7. 记录实际释放、分离及抬离结果。若错过现场快照，明确标注缺失；后续空载补录只能算候选位置，不能补称为当时实际姿态。

每次命令均为 ` .\.venv\Scripts\python.exe record_robot_pose.py 标签`。工具只读，保存端点不代表保存了路径，不解除自动回放禁用。
