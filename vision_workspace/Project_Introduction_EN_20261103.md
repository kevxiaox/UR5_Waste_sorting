# Intelligent Waste Sorting with a UR5 Robot

Our project develops a robotic waste-sorting demonstrator combining computer vision, motion planning and a collaborative robot. The system uses an overhead ZED Mini camera to observe the workspace, a YOLO model to identify objects, a UR5 robotic arm and an OnRobot RG6 gripper to pick them up and place them in the appropriate sorting area. Plastic bottles, aluminium cans and paper cups are assigned to the recyclable area, while sponges are assigned to the residual-waste area.

The software connects the detection results to a pick-and-place state machine. It checks the detected class, confidence and image location, then selects a destination and a grasp reference. For the current demonstration, each object is placed at a previously taught position; the camera determines the object's class rather than providing a validated arbitrary-position grasp. A motion planner computes and checks the movements through the approach, grasp, lift, transfer, release and retreat stages. The robot and gripper are controlled through RTDE, with operator confirmations during the supervised demonstration.

The team recorded reference positions for the four object types and integrated a complete pick-and-place workflow. According to the project test records, the real robot completed supervised cycles using recorded detection results. The connection between live camera detection and the real robot is implemented but still requires on-site validation. Future work includes validating camera-to-robot calibration, modelling the physical workspace more accurately and using gripper feedback to confirm successful grasps. The objective is to move from fixed-position, supervised sorting toward a more autonomous and flexible system.
